# ✨ Люмос — карманный дух-компаньон

Живой виртуальный питомец, который **продолжает жить, пока вас нет**: спит и видит сны, учит новые слова, рисует картины, наводит порядок и — немного — скучает. Полностью статическая игра для GitHub Pages: без бэкенда, без регистрации, всё хранится в браузере игрока.

> «Меня кто-то ждёт и помнит» — ключевая фантазия игры.

## Что внутри

| Система | Описание |
|---|---|
| **Процедурная генерация** | 8 архетипов (пушистик, дух рощи, дракоша, звёздное дитя, сновидец-блоб, космический зверь, цифровой фамильяр, лесной топотун) × формы, уши, хвосты, узоры, палитры, ауры. Каждый питомец уникален и воспроизводим по сиду. |
| **Офлайн-жизнь** | При возвращении — экран «С возвращением» с хроникой: сны с подарками, уборка, выученные слова, рисунки. Мягкие полы характеристик: питомец скучает, но не погибает. |
| **Характер и память** | Темперамент, любимое/нелюбимое, 6 навыков. Правилевой ИИ-чат запоминает имя, предпочтения, факты и обещания хозяина и вплетает их в речь. |
| **Стиль заботы → внешность** | Чтение даёт очки мудрости, прогулки — рюкзачок искателя, высокая связь — сияющее сердце над головой. Забота буквально формирует существо. |
| **Живая сцена** | Реальное время суток и сезонная погода за окном, светлячки ночью, дождь и снег. Питомец дышит, моргает и следит глазами за курсором. |
| **Игры и забота о хозяине** | «Звёздная память», «Лови светлячков», дыхательная практика 4-2-6, фокус-таймер, аффирмации. |
| **Наследие** | Бережная трансценденция в духа памяти: эпитафия, дар дереву наследия, новое яйцо наследует цвет и бонус предка. |
| **Дневник, сны, память** | Три журнала: записи питомца, осколки снов, структурированные воспоминания. |

Полный дизайн-документ (20 разделов: архитектура, модель данных, эмоциональный дизайн, дорожная карта) встроен прямо в игру — вкладка **«Док»**.

## Технологии

- **Vite + React 18 + TypeScript**, Tailwind CSS v4
- Игровой движок — чистый ES6-синглтон (`src/game/engine.ts`), не зависим от React
- Сохранения: `localStorage` (~10 КБ) + экспорт/импорт сейва в base64
- Звук: WebAudio-синтез без аудиофайлов, только по жесту пользователя
- Графика: процедурный SVG-питомец и сцена — ноль растровых ассетов

## Структура проекта

```
src/
├── game/            # движок вне React
│   ├── engine.ts    # GameEngine: состояние, уход, офлайн-симуляция, наследие
│   ├── dna.ts       # PetDNA: генератор питомцев, виды, редкость
│   ├── speech.ts    # ChatBrain, сны, дневник, проактивные реплики
│   ├── content.ts   # еда, лавка, квесты, стадии жизни, темы комнаты
│   ├── sound.ts     # WebAudio-синтезатор
│   └── types.ts     # модель данных
├── components/      # сцена, спрайт, HUD, панели, мини-игры, экраны
└── App.tsx          # игровой цикл и навигация
```

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # прод-сборка в dist/
```

## Публикация на GitHub Pages

### 1. Создание репозитория и первый push

```bash
git init
git add .
git commit -m "feat: Люмос — карманный дух-компаньон"
git branch -M main
git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
git push -u origin main
```

### 2. Деплой (автоматический)

В репозитории уже настроен воркфлоу `.github/workflows/deploy-pages.yml` — он собирает проект с относительными путями (`--base=./`) и публикует `dist/` при каждом пуше в `main`.

Останется один раз включить Pages:

**Settings → Pages → Source: GitHub Actions**

Через минуту игра будет доступна по адресу `https://<ВАШ_ЛОГИН>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/`.

### Альтернатива: ручной деплой

```bash
npm run build -- --base=./
npx gh-pages -d dist
```

> Сейвы хранятся в `localStorage` посетителя. Для переноса между устройствами в игре есть экспорт/импорт сохранения (Настройки → «Перенос сохранения»).
