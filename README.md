# ✨ Люмос — карманный дух-компаньон

Живой виртуальный питомец, который **продолжает жить, пока вас нет**: спит и видит сны, учит новые слова, рисует картины, наводит порядок и — немного — скучает. Полностью статическая игра для GitHub Pages: без бэкенда, без регистрации, всё хранится в браузере игрока.

> «Меня кто-то ждёт и помнит» — ключевая фантазия игры.

## Что внутри

| Система | Описание |
|---|---|
| **Процедурная генерация** | 10 архетипов (пушистик, дух рощи, дракоша, звёздное дитя, сновидец-блоб, космический зверь, цифровой фамильяр, лесной топотун, **лисёнок**, **туманный котёнок**) с единой «анатомией»: ножки, лапки, мордочки, усы, клыки, зрачки. |
| **Офлайн-жизнь** | При возвращении — экран «С возвращением» с хроникой: сны с подарками, уборка, выученные слова, рисунки. |
| **Живые анимации ухода** | Поглаживание — сердечки и подпрыгивание; уборка — метла с облачками пыли; купание — пузыри и всплеск. Питомец моргает, дышит, следит глазами за курсором, засыпает сам ночью. |
| **Настоящая учёба** | Викторины по географии, физике, биологии и обществознанию (48 вопросов) + случайные факты из Википедии — прямо из интернета. |
| **Прогулки** | 5 локаций (парк, пекарня, библиотека, набережная + улицы вашего города) — у каждой своя сцена: холмы и цветы, витрина с паром из трубы, парящие книги, волны и лодочка, городской skyline с котом на скамейке. |
| **Реальная погода** | По городу игрока (Open-Meteo, без ключа): дождь и снег идут за окном комнаты. Город спрашивается при знакомстве и в настройках. |
| **6 мини-игр** | «Звёздная память», «Лови светлячков», «Эхо-мелодия» (Simon), **«Виселица»** (отгадывание по буквам), «Звёздные пятнашки», «Судоку» (4 сложности, генератор с единственным решением). |
| **Характер и память** | Темперамент, любимое/нелюбимое, 6 навыков. Чат запоминает имя, предпочтения, факты и обещания хозяина. |
| **Разговорный ИИ** | Гибрид: диалоговый движок с намерениями + предобученная крошечная нейросеть (эмбеддинги → скрытый слой → softmax). Питомец здоровается по времени суток, отвечает «как дела» и «что делал», **задаёт встречные вопросы и помнит ответы** (имя, настроение, любимое), шутит, считает, рассказывает факты и делится новостями. Сеть обучается на каждом разговоре и выгружается отдельной моделью. |
| **Наследие** | Бережная трансценденция в духа памяти: эпитафия, дар дереву наследия, новое яйцо наследует цвет и бонус предка. |

Полный дизайн-документ (20 разделов) встроен прямо в игру — вкладка **«Док»**.

## Технологии

- **Vite + React 18 + TypeScript**, Tailwind CSS v4
- Игровой движок — чистый ES6-синглтон (`src/game/engine.ts`), не зависим от React
- Сохранения: `localStorage` + экспорт/импорт сейва в base64
- Звук: WebAudio-синтез без аудиофайлов, только по жесту пользователя
- Графика: процедурный SVG-питомец и сцена — ноль растровых ассетов

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # прод-сборка в dist/
```

## Публикация на GitHub Pages

### 1. Создание репозитория и первый push

```bash
git init
git add .
git commit -m "feat: Люмос — карманный дух-компаньон"
git branch -M main
git remote add origin https://github.com/<ВАШ_ЛОГИН>/<ИМЯ_РЕПОЗИТОРИЯ>.git
git push -u origin main
```

### 2. Деплой (автоматический)

В репозитории уже настроен воркфлоу `.github/workflows/deploy-pages.yml` — он собирает проект с относительными путями (`--base=./`) и публикует `dist/` при каждом пуше в `main`.

Останется один раз включить Pages:

**Settings → Pages → Source: GitHub Actions**

Через минуту игра будет доступна по адресу `https://<ВАШ_ЛОГИН>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/`.

### Альтернатива: ручной деплой

```bash
npm run build -- --base=./
npx gh-pages -d dist
```

> Сейвы хранятся в `localStorage` посетителя. Для переноса между устройствами в игре есть экспорт/импорт сохранения (Настройки → «Перенос сохранения»).

## Управление

- **Тап/клик по питомцу** — погладить (с анимацией сердечек)
- **Быстрые кнопки под сценой** — кухня, гладить, уборка, купать, спать, учиться, гулять; на ПК дублируются клавишами **1–7**
- **Вкладки** — Комната · Забота · Игры · Болталка · Дневник · Док
