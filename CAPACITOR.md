# 📱 Люмос как нативное приложение (Android + iOS)

Игра уже полностью готова к оборачиванию в нативное приложение через **Capacitor**.
Весь нативный слой написан и подключён: сплэш-скрин, статус-бар, вибрация,
пуш-уведомления и жизненный цикл. Ниже — как получить установочные файлы.

---

## Что уже сделано в коде

| Файл | Назначение |
|---|---|
| `capacitor.config.ts` | appId `com.lumos.companion`, сплэш (ночной фон, скрывается программно), статус-бар |
| `src/native/platform.ts` | Инициализация: скрытие сплэша, цвет статус-бара по времени суток, обработка фона/возврата |
| `src/native/notify.ts` | Пуш-уведомления: «проголодался», «скучает», «проснулся» — ставятся по реальным характеристикам |
| `src/native/haptics.ts` | Вибрация: мурчание (поглаживание), толчок (уборка/купание), «успех» (уровень/ритуал) |
| `public/manifest.webmanifest` + `public/icons/icon.svg` | PWA-манифест и иконка |

Все нативные вызовы — безопасные no-op в браузере, поэтому веб-версия не меняется.

---

## Быстрый старт (локально)

```bash
# 1) собрать веб-бандл с относительными путями
npm run build -- --base=./

# 2) добавить платформы (создаст папки android/ и ios/)
npx cap add android
npx cap add ios

# 3) скопировать dist/ в нативные проекты
npx cap sync

# 4) открыть в IDE и собрать
npx cap open android   # Android Studio → Build → Build APK
npx cap open ios       # Xcode → Product → Archive
```

После `cap add` запускайте `npm run build -- --base=./ && npx cap sync` после каждого
изменения кода, чтобы игра обновлялась в приложении.

## Android: готовый APK

### Вариант A — автоматически (рекомендуется)
В репозитории настроен воркфлоу **`.github/workflows/build-android.yml`**.
Пушьте код — зайдите в **Actions → Build Android APK → Run workflow**.
Через несколько минут готовый `app-debug.apk` появится в артефактах —
скачайте и установите на телефон.

### Вариант B — локально
Нужны [Android Studio](https://developer.android.com/studio) и JDK 17.
```bash
npx cap open android
```
В Android Studio: **Build → Build Bundle(s)/APK(s) → Build APK(s)**.
Файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

Для публикации в Google Play нужен подписанный AAB:
**Build → Generate Signed Bundle** (создайте keystore) → `app-release.aab`.

---

## iOS: готовое приложение

Нужны **macOS + Xcode** и аккаунт Apple Developer ($99/год) для установки
на устройство и публикации в App Store. Без аккаунта — только симулятор.

```bash
npx cap open ios
```
В Xcode: выбрать свою Team (подпись) → **Product → Archive** →
Distribute App (App Store / Ad Hoc) или **Run** для симулятора/устройства.

## Иконки и сплэш всех размеров

Встроенная SVG-иконка подходит для веба. Для нативных launcher-иконок и
сплэш-скринов всех разрешений сгенерируйте PNG из одного квадратного
изображения (минимум 1024×1024):

```bash
# положите исходник в resources/icon.png (и resources/splash.png 2732×2732), затем:
npm i -D @capacitor/assets
npx capacitor-assets generate --iconBackgroundColor '#0c1220' --splashBackgroundColor '#0c1220'
```
Команда сама разложит иконки и сплэш по всем папкам `android/` и `ios/`.

## Поведение нативных фич

- **Сплэш** — показывается при запуске, скрывается, когда движок готов.
- **Статус-бар** — цвет подстраивается под время суток в игре (утро/день/вечер/ночь), иконки светлые.
- **Вибрация** — поглаживание = мягкое мурчание; уборка/купание/кормление = ощутимый толчок; уровень/ритуал/подарок = «успех».
- **Пуши** — когда игра уходит в фон, по текущей сытости и скорости её распада
  вычисляется, *когда* питомец проголодается, и уведомление ставится ровно на этот
  момент. При возврате все пуши гасятся. Требуется разрешение (запрашивается автоматически).

---

## Важно про «нативность»

Capacitor даёт **настоящее нативное приложение** (реальные `.apk`/`.ipa`, установка
из сторов, доступ к вибрации/пушам/статус-бару), внутри которого игра работает в
WebView. Визуально и по ощущениям оно неотличимо от полностью нативного, но весь
код — один TypeScript, что упрощает поддержку. Полностью нативная переписать
(Swift/Kotlin) потребовала бы дублирования всей логики питомца и не даёт
практических преимуществ для этой игры.
